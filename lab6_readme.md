# Image Captioning with InceptionV3 and LSTM

This project implements an **Image Captioning** model using **InceptionV3** for feature extraction and **LSTM** for sequence generation. The dataset used is **Flickr8k**, a popular collection of 8,000 images with corresponding captions.

## Project Details

- **Model Architecture**: 
  - **InceptionV3**: Used for extracting features from images.
  - **LSTM**: Used to generate captions based on the extracted features.
- **Dataset**: Flickr8k dataset containing images with multiple captions.
