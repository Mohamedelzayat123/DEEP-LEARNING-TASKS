# Fashion MNIST Classification with ANN

## Objective
The goal of this project is to build an Artificial Neural Network (ANN) to classify clothing items from the Fashion MNIST dataset. The model will learn to identify 10 different categories of clothing.

## Dataset Description
Fashion MNIST is a dataset of 70,000 grayscale images, each 28x28 pixels, divided into 10 categories:
- **Training set**: 60,000 images
- **Test set**: 10,000 images
- **Categories**: 
  1. T-shirt/top
  2. Trouser
  3. Pullover
  4. Dress
  5. Coat
  6. Sandal
  7. Shirt
  8. Sneaker
  9. Bag
  10. Ankle boot

## Dependencies
The following packages are required to run the project:

    tensorflow==2.13.0 (or your installed version)
    numpy
    matplotlib
    seaborn
    scikit-learn
## Expected Results
    Test Accuracy: ~85-90%
    Loss: ~0.3-0.5

The model should perform well on the Fashion MNIST dataset, achieving reasonable accuracy with minimal overfitting.
